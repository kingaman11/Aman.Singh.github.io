🤖 Automated Anomaly Detection & Root Cause Analysis

At Roku, I've built an automated workflow that transforms how we monitor payment fluctuations. Instead of manually investigating every spike or dip, I use Claude Code to orchestrate an intelligent system that detects anomalies and investigates root causes.

The Workflow:

1. Data Pipeline (Airflow DAG) Daily Airflow DAG pulls payment metrics from our data warehouse. When it detects a significant deviation (revenue up 15% or down 10%), it triggers the anomaly investigation workflow.
2. Claude Code Analysis Claude Code analyzes data patterns, compares historical trends, and identifies which dimensions are most affected (geography, payment method, subscription tier).
3. Web Scraping & MCP Integration Claude Code uses MCP servers to investigate external factors:
  • Web Search: Recent news about content releases, sports events, streaming trends
  • Gleam: Entertainment news, social media trends, competitor announcements
  • Custom MCPs: Marketing campaigns, content updates, support tickets
4. Hypothesis Generation Claude synthesizes all data to generate ranked hypotheses. Example: "Revenue spike correlates with [Show] Season 2 launch + social media mentions + marketing timing."
5. Executive Summary Claude generates structured reports for leadership with anomaly description, root causes, supporting evidence, and recommendations.

Real Impact:

What used to take 4-6 hours of manual investigation now takes 15 minutes. Catches patterns I would have missed — like correlations between content releases and payment method preferences.

Time saved: 10+ hours/week
Accuracy: 85%+ correlation
Value: Faster decisions, proactive optimization
